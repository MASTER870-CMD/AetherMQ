# Contributing to AetherMQ
First off, thank you for considering contributing to AetherMQ! It's people like you that make AetherMQ such a great tool.

## Code of Conduct
By participating in this project, you are expected to uphold our Code of Conduct.

## How Can I Contribute?
### Reporting Bugs
Before creating bug reports, please check the existing issues as you might find out that you don't need to create one.

When you are creating a bug report, please include as many details as possible.

### Suggesting Enhancements
Enhancement suggestions are tracked as GitHub issues. Provide a clear and descriptive title.

### Your First Pull Request
Unsure where to begin contributing? You can start by looking through these beginner and help-wanted issues.

## Environment Setup
1. Node.js (v18+)
2. TypeScript
